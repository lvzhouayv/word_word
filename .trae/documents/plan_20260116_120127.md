# 联网搜索更多例句和单词短语功能设计

## 功能需求
1. 增加联网搜索功能，可以搜索更多例句和单词短语
2. 无网络时无法搜索，但不影响本地功能
3. 第一次获取的数据保存在本地，方便下次使用

## 技术方案

### 1. 数据库设计

**扩展单词表**：
- 添加 `is_local` 字段：标识数据是否为本地数据
- 添加 `last_updated` 字段：记录数据最后更新时间

**新增例句表 (word_examples)**：
```sql
CREATE TABLE word_examples (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  word_id INTEGER,
  example_text TEXT,
  translation TEXT,
  source TEXT,
  FOREIGN KEY (word_id) REFERENCES word(word_id)
);
```

**新增短语表 (word_phrases)**：
```sql
CREATE TABLE word_phrases (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  word_id INTEGER,
  phrase TEXT,
  translation TEXT,
  source TEXT,
  FOREIGN KEY (word_id) REFERENCES word(word_id)
);
```

### 2. 网络请求模块

**API选择**：
- 可以使用 Youdao API 或其他免费的英语词典API
- 或使用公开的例句API服务

**实现思路**：
- 在 `main.js` 中添加网络请求函数
- 处理网络超时和错误情况
- 实现数据解析和转换

### 3. 本地缓存机制

**缓存策略**：
- 第一次搜索时，将结果保存到 `word_examples` 和 `word_phrases` 表
- 后续使用时，优先从本地读取数据
- 提供手动刷新功能，更新本地缓存

### 4. UI界面设计

**扩展学习界面**：
- 添加例句和短语标签页
- 显示搜索状态和来源
- 提供刷新按钮
- 显示网络状态

**扩展单词总览界面**：
- 添加快速查看例句和短语的功能

### 5. 代码实现

**main.js**：
- 添加数据库初始化代码
- 实现网络请求函数
- 添加IPC处理函数

**renderer.js**：
- 添加例句和短语的UI组件
- 实现搜索和显示逻辑
- 处理网络状态

**index.html**：
- 扩展学习界面，添加例句和短语标签
- 添加刷新按钮
- 显示网络状态

## 实现步骤

1. **数据库扩展**：修改 `main.js` 中的数据库初始化代码
2. **网络模块**：实现API请求和数据解析
3. **UI扩展**：修改HTML和CSS，添加例句和短语显示区域
4. **逻辑实现**：在renderer.js中实现搜索和缓存逻辑
5. **测试**：测试网络请求、本地缓存和无网络情况

## 预期效果

- 联网时可搜索更多例句和短语
- 数据自动保存到本地
- 无网络时使用本地缓存
- 用户可手动刷新数据
- 清晰显示数据来源和更新时间

## 代码示例

```javascript
// main.js 中的网络请求示例
async function fetchWordExamples(word) {
  try {
    const response = await axios.get('https://api.example.com/examples', {
      params: { word },
      timeout: 5000
    });
    return response.data.examples;
  } catch (error) {
    console.error('Failed to fetch examples:', error);
    return [];
  }
}

// renderer.js 中的搜索逻辑
async function searchMoreExamples(wordId, english) {
  // 先检查本地是否已有数据
  const localExamples = await ipcRenderer.invoke('get-local-examples', wordId);
  if (localExamples.length > 0) {
    displayExamples(localExamples);
    return;
  }
  
  // 检查网络状态
  if (!navigator.onLine) {
    showNoNetworkMessage();
    return;
  }
  
  // 联网搜索
  const examples = await ipcRenderer.invoke('fetch-examples', english);
  if (examples.length > 0) {
    // 保存到本地
    await ipcRenderer.invoke('save-examples', wordId, examples);
    displayExamples(examples);
  } else {
    showNoExamplesMessage();
  }
}
```
