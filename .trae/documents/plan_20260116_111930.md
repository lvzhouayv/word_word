# 调整主题预览图大小

## 问题分析
用户反馈浅色主题和深色主题的背景预览图太大，需要减小尺寸。

## 解决方案
修改 `styles.css` 文件中的 `.theme-preview` 样式，减小预览图的宽度和高度。

## 具体修改

1. **主题预览图样式**：将宽度从 80px 减小到 60px，高度从 60px 减小到 45px
2. **主题按钮样式**：相应调整按钮的内边距和最小宽度，保持整体协调

## 修改代码

```css
/* 主题预览图 */
.theme-preview {
  width: 60px;               /* 宽度 - 从80px减小到60px */
  height: 45px;              /* 高度 - 从60px减小到45px */
  border-radius: 6px;        /* 圆角 - 6px */
  background-size: cover;     /* 背景大小 - 覆盖整个元素 */
  background-position: center; /* 背景位置 - 居中 */
  background-repeat: no-repeat; /* 背景重复 - 不重复 */
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15); /* 阴影 - 半透明黑色 */
  transition: transform 0.3s; /* 过渡效果 - 变换变化时的动画 */
}

/* 主题按钮 - 浅色、深色、自定义主题按钮 */
.theme-btn {
  padding: 10px 12px;         /* 内边距 - 上下10px，左右12px */
  border: 2px solid var(--action-btn-border); /* 边框 - 2px实线，使用主题变量 */
  border-radius: 8px;          /* 圆角 - 8px */
  background: var(--action-btn-bg); /* 背景 - 使用主题变量 */
  cursor: pointer;             /* 鼠标样式 - 指针 */
  font-size: 14px;            /* 字体大小 - 14px */
  color: var(--action-btn-text); /* 颜色 - 使用主题变量 */
  transition: all 0.3s;       /* 过渡效果 - 所有属性变化时的动画 */
  display: flex;              /* 显示方式 - 弹性布局 */
  flex-direction: column;       /* 弹性方向 - 垂直排列 */
  align-items: center;         /* 交叉轴对齐 - 居中对齐 */
  gap: 6px;                  /* 间距 - 6px */
  min-width: 80px;           /* 最小宽度 - 从100px减小到80px */
}
```

## 预期效果
主题预览图将从 80px×60px 减小到 60px×45px，整体布局更加紧凑，符合用户需求。
