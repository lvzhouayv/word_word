# 统一学习界面字体颜色为纯黑色

## 问题分析
学习界面的字体颜色目前使用的是深灰色(#333)和中灰色(#666)，用户希望改为纯黑色(#000000)以提高可读性。

## 解决方案
修改CSS变量定义，将主要和次要文字颜色统一改为纯黑色，同时保持深色主题的可读性。

## 具体修改

1. **修改CSS变量定义**：
   - 将默认主题的`--text-primary`和`--text-secondary`改为纯黑色
   - 将浅色主题的`--text-primary`和`--text-secondary`改为纯黑色
   - 保持深色主题的文字颜色不变，确保可读性

2. **修改学习卡片样式**：
   - 确保学习卡片的所有文本元素都使用统一的文字颜色
   - 调整透明度和对比度，确保黑色字体在浅色背景上清晰可见

## 修改代码

```css
/* 通用选择器 - 重置所有元素的默认样式 */
:root {
  /* 文字颜色变量 */
  --text-primary: #000000;     /* 主要文字颜色 - 纯黑色 */
  --text-secondary: #000000;   /* 次要文字颜色 - 纯黑色 */
  /* 其他变量保持不变 */
}

/* ==================== 浅色主题 ==================== */
body.light-theme {
  /* 文字颜色 - 纯黑色 */
  --text-primary: #000000;
  --text-secondary: #000000;
  /* 其他变量保持不变 */
}

/* ==================== 学习卡片 ==================== */
.word-card {
  /* 确保文字在半透明背景上清晰可见 */
  backdrop-filter: blur(var(--card-blur)); /* 背景模糊 - 使用主题变量 */
  -webkit-backdrop-filter: blur(var(--card-blur)); /* 背景模糊 - Safari浏览器支持 */
}

/* 确保所有学习卡片元素使用统一的黑色文字 */
.word-card .word,
.word-card .phonetic,
.word-card .definition,
.word-card .example {
  color: #000000 !important;
}

/* 深色主题下保持白色文字，确保可读性 */
body.dark-theme .word-card .word,
body.dark-theme .word-card .phonetic,
body.dark-theme .word-card .definition,
body.dark-theme .word-card .example {
  color: #ffffff !important;
}
```

## 预期效果
学习界面的所有文字（单词、音标、释义、例句）将统一显示为纯黑色，在浅色背景上具有更好的可读性。深色主题下仍保持白色文字，确保在深色背景上的可读性。
